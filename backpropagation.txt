USER:
could you explain to me the cost function in a neural network makin an example where we have 3 layers of 2 neurons each (and therefore 8 weight and 4 biases). How is the cost function written and how is deteemined the gradient mathematically?

ASSISTANT:

Absolutely. The key idea is:

The cost function tells us how wrong the network is, and the gradient tells us how each weight and bias should change to reduce that cost.

Let's build the whole thing mathematically for a small network.

1. OUR NETWORK

Suppose we have:

- 2 input neurons
- 2 neurons in hidden layer 1
- 2 neurons in hidden layer 2
- 2 output neurons

So:

    x -> Layer 1 -> Layer 2 -> Output

There are 3 layers containing weights, each with 2 neurons.

If each layer connects 2 neurons to 2 neurons, then each layer has:

    2 x 2 = 4

weights.

Therefore:

    4 + 4 + 4 = 12

weights, and:

    2 + 2 + 2 = 6

biases.

So, with three trainable layers of 2 neurons each, the network actually has 12 weights + 6 biases, not 8 weights + 4 biases.

If by "3 layers of 2 neurons each" you meant input -> hidden -> output, then there are only two weight matrices:

    2 x 2 + 2 x 2 = 8

weights and:

    2 + 2 = 4

biases.

I think that's the network you intended, so let's use that.

2. THE 2 -> 2 -> 2 NETWORK

Our network is:

    (x1, x2)
        |
        v
    (h1, h2)
        |
        v
    (y1, y2)

There are 8 weights:

    W^(1) =
        [ w11^(1)  w12^(1) ]
        [ w21^(1)  w22^(1) ]

and

    W^(2) =
        [ w11^(2)  w12^(2) ]
        [ w21^(2)  w22^(2) ]

And four biases:

    b^(1) =
        [ b1^(1) ]
        [ b2^(1) ]

    b^(2) =
        [ b1^(2) ]
        [ b2^(2) ]

We can write the entire network compactly as:

    z^(1) = W^(1) x + b^(1)

    a^(1) = sigma(z^(1))

then:

    z^(2) = W^(2) a^(1) + b^(2)

and finally:

    y_hat = sigma(z^(2))

Here y_hat is the network's prediction.

3. LET'S PUT ACTUAL NUMBERS IN

Suppose our input is:

    x =
        [ 1 ]
        [ 2 ]

and the desired answer is:

    y =
        [ 0 ]
        [ 1 ]

Suppose our weights and biases happen to be:

    W^(1) =
        [ 0.5  -0.3 ]
        [ 0.8   0.2 ]

    b^(1) =
        [ 0.1 ]
        [-0.2 ]

and:

    W^(2) =
        [ 0.7  -0.4 ]
        [ 0.3   0.9 ]

    b^(2) =
        [ 0.2 ]
        [-0.1 ]

Let's use the sigmoid activation:

    sigma(z) = 1 / (1 + e^(-z))

4. FORWARD PROPAGATION

First layer:

    z^(1) = W^(1) x + b^(1)

so:

    [ z1^(1) ]   [ 0.5  -0.3 ] [ 1 ]   [ 0.1 ]
    [ z2^(1) ] = [ 0.8   0.2 ] [ 2 ] + [-0.2]

Therefore:

    z1^(1) = 0.5(1) - 0.3(2) + 0.1
           = 0

and:

    z2^(1) = 0.8(1) + 0.2(2) - 0.2
           = 1

Thus:

    z^(1) =
        [ 0 ]
        [ 1 ]

Apply sigmoid:

    a^(1) =
        [ sigma(0) ]
        [ sigma(1) ]

             [ 0.5   ]
        ~=   [ 0.731 ]

Now the second layer:

    z^(2) = W^(2) a^(1) + b^(2)

So:

    z1^(2) = 0.7(0.5) - 0.4(0.731) + 0.2
           ~= 0.258

and:

    z2^(2) = 0.3(0.5) + 0.9(0.731) - 0.1
           ~= 0.708

Applying sigmoid:

    y_hat =
        [ sigma(0.258) ]
        [ sigma(0.708) ]

        ~= [ 0.564 ]
           [ 0.670 ]

Our network predicted:

    y_hat = (0.564, 0.670)

while the correct answer was:

    y = (0, 1)

So the network is wrong.

5. WHERE DOES THE COST FUNCTION COME IN?

We need a number that tells us how wrong the prediction is.

A very common cost function for regression is mean squared error:

    C = (1/2) sum_i (y_hat_i - y_i)^2

For our two outputs:

    C = (1/2) [
            (y_hat_1 - y_1)^2
          + (y_hat_2 - y_2)^2
        ]

Plugging in:

    C = (1/2) [
            (0.564 - 0)^2
          + (0.670 - 1)^2
        ]

Therefore:

    C ~= 0.213

So we have a single number:

    C ~= 0.213

that measures the error of this particular network for this particular example.

6. BUT HOW DO WE IMPROVE THE NETWORK?

Our network has 12 parameters for the 2 -> 2 -> 2 example:

    theta = (w1, w2, ..., w8, b1, b2, b3, b4)

The cost is therefore actually a function of all those parameters:

    C = C(w1, w2, ..., w8, b1, b2, b3, b4)

Conceptually, imagine that we change one weight slightly.

For example:

    w1 -> w1 + 0.001

The prediction changes.

Therefore the cost changes.

We can ask:

"If I increase w1 slightly, does the cost go up or down?"

Mathematically, that's the partial derivative:

    dC/dw1

For every parameter we calculate one derivative:

    dC/dw1
    dC/dw2
    ...
    dC/db4

These collectively form the gradient:

    grad C =
        [ dC/dw1 ]
        [ dC/dw2 ]
        [   ...   ]
        [ dC/db4 ]

The gradient points in the direction in parameter-space in which the cost increases most rapidly.

Therefore, to decrease the cost, we go in the opposite direction.

7. GRADIENT DESCENT

This gives us the famous rule:

    w_new = w_old - eta * dC/dw

where eta is the learning rate.

For example, suppose:

    dC/dw1 = 0.4

and:

    eta = 0.1

Then:

    w1_new = w1 - 0.1(0.4)
           = w1 - 0.04

So we decrease w1.

But if:

    dC/dw1 = -0.4

then:

    w1_new = w1 - 0.1(-0.4)
           = w1 + 0.04

So we increase it.

That's what the gradient is telling us.

8. HOW DO WE CALCULATE THE GRADIENT?

This is where backpropagation comes from.

Let's take just one parameter and follow its influence through the network.

Consider w11^(2).

It affects:

    w11^(2)
        |
        v
    z1^(2)
        |
        v
    y_hat_1
        |
        v
        C

Therefore, using the chain rule:

    dC/dw11^(2)
      =
    (dC/dy_hat_1)
    (dy_hat_1/dz1^(2))
    (dz1^(2)/dw11^(2))

This is the fundamental idea behind backpropagation.

9. FIRST DERIVATIVE: COST WITH RESPECT TO OUTPUT

Recall:

    C = (1/2) sum_i (y_hat_i - y_i)^2

Therefore:

    dC/dy_hat_1 = y_hat_1 - y_1

For our example:

    dC/dy_hat_1 = 0.564 - 0
                = 0.564

10. SECOND DERIVATIVE: SIGMOID

We have:

    y_hat_1 = sigma(z1^(2))

The derivative of sigmoid is:

    sigma'(z) = sigma(z)(1 - sigma(z))

Therefore:

    dy_hat_1/dz1^(2)
        =
    y_hat_1(1 - y_hat_1)

So:

    = 0.564(1 - 0.564)
    ~= 0.246

11. THIRD DERIVATIVE: THE WEIGHT

Remember:

    z1^(2)
      =
    w11^(2) a1^(1)
    + w12^(2) a2^(1)
    + b1^(2)

Therefore:

    dz1^(2)/dw11^(2)
        =
    a1^(1)

And we calculated:

    a1^(1) = 0.5

Therefore:

    dz1^(2)/dw11^(2) = 0.5

12. PUT THE CHAIN TOGETHER

Now:

    dC/dw11^(2)
      =
    (dC/dy_hat_1)
    (dy_hat_1/dz1^(2))
    (dz1^(2)/dw11^(2))

Numerically:

    = (0.564)(0.246)(0.5)

Thus:

    dC/dw11^(2) ~= 0.0693

That's one element of our gradient.

So if the learning rate is:

    eta = 0.1

then:

    w11^(2)_new
      =
    w11^(2)_old
    - 0.1(0.0693)

Since the old value was 0.7:

    w11^(2)_new ~= 0.6931

The network has just learned.

13. WHAT ABOUT A WEIGHT IN THE FIRST LAYER?

This is where things become more interesting.

Consider:

    w11^(1)

This weight affects:

    w11^(1)
        |
        v
    z1^(1)
        |
        v
    a1^(1)
        |
        +------------------+
        |                  |
        v                  v
     z1^(2)             z2^(2)
        |                  |
        v                  v
      y_hat_1           y_hat_2
        |                  |
        +--------+---------+
                 |
                 v
                 C

So there are multiple paths from the weight to the cost.

The chain rule gives:

    dC/dw11^(1)
      =
    (dC/dz1^(2))
    (dz1^(2)/da1^(1))
    (da1^(1)/dz1^(1))
    (dz1^(1)/dw11^(1))

    +

    (dC/dz2^(2))
    (dz2^(2)/da1^(1))
    (da1^(1)/dz1^(1))
    (dz1^(1)/dw11^(1))

Notice the two terms.

Why?

Because a1^(1) influences both output neurons.

This is why backpropagation is essentially an efficient implementation of the chain rule for a computational graph.

14. THE MATRIX VERSION

Instead of doing all of these derivatives individually, we can express the entire thing elegantly.

For the final layer:

    delta^(2) = grad_z2 C

For our squared-error + sigmoid example:

    delta^(2)
      =
    (y_hat - y)
    elementwise_multiplied_by
    sigma'(z^(2))

Then the gradient of the weights is:

    dC/dW^(2)
      =
    delta^(2) (a^(1))^T

and:

    dC/db^(2)
      =
    delta^(2)

Then we propagate the error backwards:

    delta^(1)
      =
    (W^(2))^T delta^(2)
    elementwise_multiplied_by
    sigma'(z^(1))

and therefore:

    dC/dW^(1)
      =
    delta^(1) x^T

and:

    dC/db^(1)
      =
    delta^(1)

Finally, gradient descent updates everything:

    W^(l)
      <-
    W^(l) - eta dC/dW^(l)

    b^(l)
      <-
    b^(l) - eta dC/db^(l)

15. THE WHOLE PROCESS

You can think of training as:

    input
      |
      | forward propagation
      v
    prediction
      |
      v
    cost C
      |
      | backpropagation
      v
    gradient grad C
      |
      | gradient descent
      v
    new weights

The really important conceptual point is:

The cost function itself doesn't tell us how to change the weights.

The derivatives of the cost function with respect to the weights do.

Yes — your first point is exactly right, with one important nuance. And eta, the learning rate, is the parameter that controls how big a step we take when following the gradient downhill.

1. WHY EARLIER-LAYER DERIVATIVES ARE MORE COMPLICATED

Suppose we have:

    x -> W^(1) -> a^(1)
       -> W^(2) -> y_hat
       -> C

If we differentiate with respect to a weight in the second layer, for example w11^(2), there is basically one chain:

    w11^(2)
        |
        v
    z1^(2)
        |
        v
    y_hat_1
        |
        v
        C

So:

    dC/dw11^(2)
      =
    (dC/dy_hat_1)
    (dy_hat_1/dz1^(2))
    (dz1^(2)/dw11^(2))

But consider w11^(1).

It influences the first hidden neuron:

    w11^(1)
        |
        v
    z1^(1)
        |
        v
    a1^(1)

But a1^(1) then influences both neurons in the next layer:

    a1^(1) -> z1^(2) -> y_hat_1 -> C

and:

    a1^(1) -> z2^(2) -> y_hat_2 -> C

So the derivative has to account for both paths:

    dC/dw11^(1)
      =
    [dC/dz1^(2)]
    [dz1^(2)/da1^(1)]
    [da1^(1)/dz1^(1)]
    [dz1^(1)/dw11^(1)]

    +

    [dC/dz2^(2)]
    [dz2^(2)/da1^(1)]
    [da1^(1)/dz1^(1)]
    [dz1^(1)/dw11^(1)]

And if you had 10 layers instead of 2, the chain becomes much longer.

This is precisely why backpropagation is useful:

It organizes all these chain-rule calculations so we don't manually expand enormous expressions.

The important point is:

Backpropagation = efficient application of the chain rule.

2. WHAT EXACTLY IS ETA?

The learning rate eta is basically a step-size parameter.

We have:

    w_new = w_old - eta (dC/dw)

Think of:

    dC/dw

as telling us:

"If you move w to the right, the cost increases/decreases at this rate."

And eta tells us:

"Okay, how far should I actually move?"

For example, suppose:

    w = 2.0

and:

    dC/dw = 0.5

If:

    eta = 0.1

then:

    w_new
      =
    2.0 - (0.1)(0.5)
      =
    1.95

We moved by:

    delta w = -0.05

But suppose instead:

    eta = 1

Then:

    w_new
      =
    2.0 - (1)(0.5)
      =
    1.5

We made a much bigger move.

3. WHY CAN'T WE JUST USE THE GRADIENT ITSELF?

You might wonder:

Why not simply do:

    w_new = w - dC/dw

You technically could, but it can be disastrous.

Imagine the gradient is:

    dC/dw = 100

Then you'd change:

    w_new = w - 100

That's potentially an enormous jump.

The learning rate lets us control this.

For example:

    eta = 0.001

would instead give:

    w_new
      =
    w - (0.001)(100)
      =
    w - 0.1

Much more reasonable.

4. THE GEOMETRIC IDEA

Imagine the cost function as a landscape.

You are somewhere on the landscape.

The derivative tells you the slope where you currently are.

If the slope is positive:

    dC/dw > 0

you need to move toward smaller w.

If the slope is negative:

    dC/dw < 0

you need to move toward larger w.

The learning rate determines how large a step you take.

5. WHAT HAPPENS IF ETA IS TOO SMALL?

Training works, but it can be very slow.

For example:

    eta = 0.000001

might mean that you need millions of updates to get close to a good solution.

6. WHAT HAPPENS IF ETA IS TOO LARGE?

This is more interesting.

You can actually jump over the minimum.

With a reasonable learning rate, we gradually approach the minimum.

With an enormous learning rate, we can keep jumping from one side to the other.

The cost may actually increase rather than decrease.

In extreme cases, training can "explode" and the weights can become enormous.

7. AN IMPORTANT POINT

The learning rate is not part of the neural network itself.

The weights and biases are parameters that the network learns:

    W, b

The learning rate is a hyperparameter chosen by us:

    eta

So:

    W, b       = parameters learned by the network

    C          = measures how wrong the network is

    grad C     = tells us which direction to change parameters

    eta        = controls how big the change is

The fundamental update is:

    new parameter
      =
    old parameter
    -
    eta
    *
    partial derivative of C with respect to parameter

8. THE CONNECTION BETWEEN THE TWO QUESTIONS

For a deep network, the derivative for an early weight can look terrifying:

    dC/dw^(1)
      =
    (dC/dz^(L))
    (dz^(L)/da^(L-1))
    ...
    (da^(2)/dz^(2))
    (dz^(2)/da^(1))
    (da^(1)/dz^(1))
    (dz^(1)/dw^(1))

But conceptually, it's still just:

    CHAIN RULE

over and over again.

And once you've calculated that derivative, the actual learning step is incredibly simple:

    w <- w - eta (dC/dw)

So:

    BACKPROPAGATION
        =
    calculate the gradient efficiently

while:

    GRADIENT DESCENT
        =
    use the gradient to update the parameters

Therefore:

    Backpropagation != Gradient Descent

Backpropagation:
    "Calculate the slopes efficiently."

Gradient descent:
    "Use those slopes to change the parameters."
